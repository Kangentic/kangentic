# Kangentic documentation

Kangentic is a cross-platform desktop Kanban for AI coding agents. Dragging a task between columns
spawns, resumes and hands off agent sessions, and each column can run its own agent and automations.

[index.md](index.md) is the map of every doc: each folder's index lists its concepts with one line
on what each holds. [log.md](log.md) records changes to these docs.
