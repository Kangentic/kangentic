# Audits

## Point-in-time findings, kept for the reasoning they record

* [Test suite audit](test-suite-audit.md) - What the test suite and CI cost on 2026-11-02 and what each tier has caught: 37,794 tests and 16.8 minutes to green, set by one web demo job and the UI tier, with little true duplication. CI structure took a PR to 10 to 12 minutes; removals barely move it. Baseline, research with sources, every workflow's verdict, and the options rejected.
* [Test suite inventory](test-suite-inventory.md) - One row per test file on 2026-11-02, the classification behind the test suite audit: tests, CI seconds, commits, reds by class, the rule that names it, and a verdict with its reason. Every row defaults to keep unless a family review or the evidence said otherwise.
* [Conversation history paging audit](conversation-history-paging-audit.md) - Whether the Conversation viewer can scroll past the 16 MiB transcript read cap (2026-10-21): per-read worker costs on transcripts up to 548 MB, seven options weighed against the August OOM, and the capped paging design built for every agent whose transcript Kangentic reads.
* [Board card drag performance audit](board-drag-perf-audit.md) - Measurements of the board card drag on a production build (2026-09-16): no dropped frames in the gesture, one stall from an xterm built mid-drag that is now held until the drop, and dev mode 4 to 7 times slower on every synchronous cost.
* [SSH remote agents, Phase 0 audit](ssh-remote-phase-0-audit.md) - Phase 0 measurements for running agent CLIs on a Linux host over SSH (2026-11-02): a helper daemon's PTYs survive every drop except KillUserProcesses=yes, a read mirror serves status in 60 ms but must never prove a file absent, and System32 ssh.exe lost bytes mid-stream so every frame carries a CRC, and ssh2 is out.
* [SSH remote agents, first-time setup audit](ssh-remote-setup-audit.md) - Results of the Add host steps for running agents on a Linux host over SSH (2026-11-03), run against a real sshd that takes a password: the fingerprint matches the host's own, a different key is refused, a key made with the password is added once and signs in with no prompt, a changed key is refused until forgotten, and the key is deleted with the host.
* [SSH transcripts, agent CLI probe audit](ssh-transcript-exports-audit.md) - What real Kimi Code 2.5.1, Goose 1.57.0 and OpenCode 1.19.5 and 2.2.5 do on a Linux host (2026-11-05), run against a stub model: Kimi's session layout and an index line that appears on the first message, Goose's and OpenCode's own exports hold everything the readers need, and a 100 MB export takes about a second, so the link is the cost. Then what real Codex 0.167.0, Gemini 0.67.0, Aider 0.86.2 and Droid 1.5.0 do (2026-11-06): each file is appended to and keeps its inode across a resume, and which claims rest on source or on a run.
* [SSH remote agents, Phase 1 audit](ssh-remote-phase-1-audit.md) - Phase 1 results for running agent CLIs on a Linux host over SSH (2026-11-03): the real link survived 20 of 20 killed ssh connections with the same PTY alive and a gap-free counter, askpass cannot supply a host-key fingerprint on Windows, and the helper bundle holds no Electron or better-sqlite3.
* [Spare worktree audit](spare-worktree-audit.md) - Whether to keep one pre-installed spare worktree per project (2026-10-31): a pnpm workspace's 25 s install becomes a 4.8 s claim, a moved spare breaks every package link, and the four bars set before measuring pass, the claim bar narrowly, so build it for projects with an init script, adopted in place, never moved.
* [Code review fan-out audit](code-review-fanout-audit.md) - Where a /code-review fan-out's tokens went on 2026-08-29 and which driver changes cut them, followed by a running table of every later review pass: pack size, finders, reads, and findings raised, fixed and refuted.
* [Transcript pipeline audit](transcript-pipeline-audit.md) - Hardening the session transcript pipeline for cross-agent use (2026-06-12): a parseTranscript per adapter, Claude parser fidelity fixes, and checks against real session files from six agents.
